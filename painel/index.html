    Arena de Agentes Autônomos

    Dois LLMs locais competem sobre um código real. O Mutante esconde um bug; o Caçador escreve testes para abatê-lo. Um árbitro determinístico decide cada jogada executando código.

    🔴 Partida ao vivo

    Roda os agentes agora, na sua GPU, via Ollama + MCP.

    Como funciona

    🧟 Agente MutanteLLM local (Ollama)
    🏹 Agente CaçadorLLM local (Ollama)
    ⇄
    MCP
    JSON-RPC · stdio
    🖥️ Servidor MCP da Arena ler_codigo · ler_testes · propor_mutacao · enviar_teste regras de turno impostas no servidor
    ⚖️ Árbitro determinístico AST · sandbox pytest · oráculo diferencial · filtro de alucinação
    1. Mutante lê o código e os testes e altera uma linha para inserir um bug sutil.
    2. O árbitro valida (AST), prova com o oráculo diferencial que o comportamento mudou (~5 mil entradas) e exige que o bug sobreviva à suíte atual.
    3. Caçador lê o código com bug (sem saber a linha) e escreve testes a partir das docstrings (a especificação).
    4. Testes que falham no código correto são alucinações e vão para o lixo. Os válidos precisam falhar no mutante para abatê-lo.
    5. Testes vencedores entram na suíte, e o próximo Mutante enfrenta uma defesa mais forte.

    🔒 Segurança

    • Anti prompt-injection entre agentes: comentários e strings longas são proibidos nas mutações.
    • Sandbox: subprocesso isolado, pasta temporária, timeout, sem os/open/eval.
    • Sem vazamento de credenciais: o servidor e a sandbox recebem um ambiente limpo.
    • Limites de autonomia: ferramentas permitidas por papel, máximo de passos e de tentativas.
